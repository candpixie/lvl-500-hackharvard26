Orbit agent evals

Read from the Chalk evaluation runs (snapshot d29cf5404f55, SOCRATES window Oct 16 to 23). Hard-coded scorers, no LLM judge.

1. Does the recommendation steer away from predicted near misses?

Score = where the chosen shell ranks among the band's shells by SOCRATES predicted close approaches (1.0 = fewest, 0.0 = most). The picker never sees SOCRATES. Chalk evaluation recommend-orbit-vs-baselines-v2.

recommend_orbitfewest objects, same inclinationweb app's current rulerandom pick
Read this honestly. recommend_orbit beats a random pick, but it does not beat the simple rules, and in the 600 to 900 km band it is no better than random. The key mostly rewards leaving the dense Starlink shells at 450 to 600 km, so a constant answer can score well in some bands.

2. Does the ask service keep recommendations out of the debris band?

58 questions run through the same code the live /ask endpoint serves (where 26, what if 17, why 7, near miss 5, crowding 3). Chalk evaluation ask-junk-band.

26 / 26"where should I put it" answers recommend a shell outside 750 to 850 km with dead-satellite lifetime under 25 years
58 / 58answers where every spoken number comes from a tool result
58 / 58answers within the house rules (no "safe", no misused "collision probability")
58 / 58questions answered with no error
It is an easy bar. All 26 recommendations were the same shell (525 km, dead-satellite lifetime about 10.6 years). The team's ranking barely changes with satellite count or size, so "always 525 km" would also score 26 of 26. It does fail naive pickers (fewest objects, busiest shell, always 800 km, always 1,000 km).
That shell, 500 to 550 km, ranks near the bottom on the near-miss measure above (0.13 at 53 degrees). The two evals measure different goals: expected harm including how long wreckage persists, versus predicted close approaches this week.
